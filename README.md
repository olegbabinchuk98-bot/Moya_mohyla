# ВМОГИЛЕ — Telegram Mini App (original-mechanics baseline)

Це стартовий каркас для відновлення старої «Вмогиле» без вигаданих сучасних предметів.

## Закладено
- 🇺🇦 🇷🇺 🇬🇧 три мови;
- landscape/fullscreen UI;
- могила, кладовище, енергія, черепки;
- клани «Белые Тапки» / «Черные Капюшоны»;
- інвентар з оригінальними категоріями;
- склеп/магазин як окремий екран;
- аватар і 4 стихії;
- база даних SQLite;
- Telegram bot launcher.

## Важливо
Нічого нового від себе в каталог предметів не додано. Предмети в `data/catalog.json` — лише ті, що підтверджені архівними матеріалами; непідтверджені позиції залишаються TODO до знаходження джерела.
